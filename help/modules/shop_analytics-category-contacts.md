# Контакты по категориям

Откройте **Магазин → Аналитика** и выберите **Контакты по категориям**
в правом меню разделов.

| До | После |
| --- | --- |
| Заказы и корзины приходилось сверять с категориями вручную | Один отчёт с выбором периода и товарных категорий |
| Контакты и состав нужно было собирать из отдельных записей | Заказы и брошенные корзины показаны отдельно, доступны две выгрузки XLSX |
| Категории для еженедельного отчёта выбирались заново | Набор сохраняется в персональном представлении; даты меняются перед выгрузкой |

## Отбор

Достаточно **одного товара** из выбранных категорий, чтобы заказ или корзина
попали в список потенциального опта. Статус покупателя в базе не меняется.

Выберите даты, раскройте категории, отметьте нужные разделы и нажмите
**Показать**. По умолчанию включены подкатегории и отбор только записей
с непустым телефоном или email.

В режиме **Заказы** доступен фильтр отмен и оплаты. В режиме
**Брошенные корзины** можно отделить отработанные от неотработанных.
Архивные корзины включены; корзины, уже превратившиеся в заказ, исключены.
Открытая корзина считается брошенной после часа бездействия.

## Даты и суммы

У заказов период относится к **созданию заказа**, у корзин — к **последней
активности**. Поэтому старая корзина, которую заполняли на этой неделе,
может попасть в недельный отчёт.

Категории определяются по текущим привязкам товаров. Состав и сумма берутся
из сохранённых данных без пересчёта по текущему прайсу. Сумма — за весь
заказ/корзину, не только за подходящие позиции. Итог заказов исключает отмены.

## Выгрузка

**XLSX** скачивает всю выборку, не только текущую страницу. Одна запись —
одна строка; несколько товаров в ячейке разделены переносами строк.
В файле также есть контакты, категории, оплата/состояние, обработка корзины,
UTM-источник и кампания, комментарий. Второй лист содержит параметры отбора.

Для заказов и брошенных корзин скачиваются отдельные файлы. Период — до
93 дней, файл — до 5000 строк; при превышении нужно сузить выборку.

Сохраните категории кнопкой закладки в «Сохранённых представлениях».
В следующий раз выберите набор и измените даты: сохранённые даты не
сдвигаются автоматически. Быстрая ссылка **Прошлая неделя** выбирает
предыдущую календарную неделю с понедельника по воскресенье.

Для просмотра нужны права на аналитику и заказы, для скачивания также право
экспорта аналитики. Готовые файлы содержат персональные контакты покупателей.
